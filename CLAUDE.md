# Claude Code guidance

The stable engineering rules for this workspace are in [AGENTS.md](AGENTS.md). Read and follow that file before making changes.

Use [SPEC.md](SPEC.md) for evolving product requirements and the README inside the project being changed for local setup and user-facing behavior. Keep those concerns separate: do not copy feature requirements into AGENTS.md, and do not turn project READMEs into implementation policy.
